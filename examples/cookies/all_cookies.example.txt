# Netscape HTTP Cookie File
# 这是 awesome-music-recap-harness 的占位演示 jar。
# 格式合法。每个值都是假的。不能登录任何人。
#
# 安装（你自己做；工具从不写这份规范文件）：
#   cp examples/cookies/all_cookies.example.txt all_cookies.txt
#   chmod 0600 all_cookies.txt
# 然后用真实浏览器导出替换每一个 PLACEHOLDER_*，
# 或用仓库外筛好的候选文件整份覆盖。
#
# yt-dlp 只能通过下面这条封装读取 jar：
#   python3 tools/video/yt_dlp_readonly.py -- <yt-dlp 参数>
# 封装会把文件拷到仓库外，避免 yt-dlp 退出时改写 all_cookies.txt。
#
# 列（制表符分隔）：domain  includeSubdomains  path  secure  expiry  name  value
# HttpOnly 行以 #HttpOnly_ 紧挨域名开头。
# expiry 4102444800 = 2100-01-01 UTC（仅演示；不是真实会话寿命）。
#
