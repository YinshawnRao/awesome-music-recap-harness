# Netscape HTTP Cookie File
# This is a PLACEHOLDER demo jar for awesome-music-recap-harness.
# It is valid Netscape format. Every value is fake. It cannot log anyone in.
#
# Install (you do this; tools never write the canonical file):
#   cp examples/cookies/all_cookies.example.txt all_cookies.txt
#   chmod 0600 all_cookies.txt
# Then replace every PLACEHOLDER_* value with a real browser export, or
# overwrite the file with a filtered candidate produced outside the repo.
#
# yt-dlp must consume the jar only via:
#   python3 tools/video/yt_dlp_readonly.py -- <yt-dlp arguments>
# The wrapper copies the file outside the repo so yt-dlp cannot rewrite
# all_cookies.txt on exit.
#
# Columns (tab-separated): domain  includeSubdomains  path  secure  expiry  name  value
# HttpOnly rows start with #HttpOnly_ immediately before the domain.
# expiry 4102444800 = 2100-01-01 UTC (demo only; not a real session lifetime).
#
# ---- YouTube / Google login-state family ----
# LOGIN_INFO + SID/HSID/SSID/SAPISID/APISID + __Secure-3PSID are the static
# fields check_yt_cookie.py requires. Several of those live on .google.com.

#HttpOnly_.google.com	TRUE	/	TRUE	4102444800	SID	PLACEHOLDER_NOT_A_SESSION_sid
#HttpOnly_.google.com	TRUE	/	TRUE	4102444800	HSID	PLACEHOLDER_NOT_A_SESSION_hsid
#HttpOnly_.google.com	TRUE	/	TRUE	4102444800	SSID	PLACEHOLDER_NOT_A_SESSION_ssid
